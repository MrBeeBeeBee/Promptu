== Promptu, Thrown to the Wolves ==
By: Benjamin Kuftic, Dennis Shelton, Liam Carroll, Tyler Beach

- Installation Instructions
 1. Download and extract the zip file provided.
 2. That's it!

- Known Bugs
 1. Angling yourself correctly when a door closes will push you out of the map
 2. Music cuts a little when looping
 3. Music can desync at lower framerates (especially if the cpu is making it hang)
 4. More than one tooltip can show up at a time
 5. Lighting shadows are inconsistent with objects that go into the ground
 6. The flashlight doesn't like thinner objects close to it (like shelves)
